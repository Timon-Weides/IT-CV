Über dieses Projekt

Diese Website ist kein einfacher Lebenslauf — sie ist selbst ein DevOps-Projekt. Der gesamte Code liegt auf GitHub und wird bei jedem Push auf den Main-Branch vollautomatisch über eine CI/CD-Pipeline auf AWS deployed.
Ziel ist die praktische Demonstration moderner Cloud- und DevOps-Konzepte in einer produktiven Umgebung.
Weitere Informationen zum Projekt, der Architektur und den verwendeten Technologien finden Sie in der ReadMe-Datei im Github-Repository.
